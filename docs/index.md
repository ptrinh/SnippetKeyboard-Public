# Snippet Keyboard

Canned replies in one tap, on iOS and Android.

- [Google Play](https://play.google.com/store/apps/details?id=uk.trinh.snippetkeyboard) · [Android APK](https://github.com/ptrinh/SnippetKeyboard-Public/releases)
- [Snippet file format](format.md) — the YAML you import and export
- [Recipes for dynamic snippets](recipes/index.md) — where to get a URL that returns text

## Support

Questions or problems: [open an issue](https://github.com/ptrinh/SnippetKeyboard-Public/issues).

## Privacy

No analytics, no tracking, no third-party SDKs. Your snippets stay on your
device. The network is used only when you tap a dynamic `https://` snippet
you created yourself.
